# Skills used in this project

- `github-session-handoff/` and `handoff/` (copied here): the save/resume system and its `/handoff` shortcut command. Re-add them to your Claude account so saving keeps working.
- `anthropic-skills:chrome-browser` (Anthropic-provided, not copied): used once to try to read a MyFitnessPal page through the Claude in Chrome extension; the extension was not connected, so the owner pasted the data instead. No custom skill beyond the two above was used.
